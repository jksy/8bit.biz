自社サービス

設計・開発・運用

resizing — 画像変換・配信 SaaS

S3 にアップロードした画像を URL パラメータでリサイズ・クロップ・フォーマット変換（WebP / AVIF / HEIC / RAW 対応）して CDN から配信するサービスです。2019年に開発を始め、商用運用は7年目に入ります。

規模
月間約2億リクエスト（CDN 経由）。本番・ステージング・開発・バックアップの4つの AWS アカウントで運用
アプリ
Ruby on Rails（puma / nginx）、Solid Queue による非同期処理、Auth0 認証、ImageMagick 7 を自前ビルド（libheif / LibRaw 同梱）
AWS
CloudFront → ALB → EC2 Auto Scaling（スポット）、S3（原本・変換キャッシュ・ログ）、Aurora MySQL、EC2 Image Builder による AMI ビルド、Athena によるアクセスログ集計
IaC / CI
Terraform（10スタック、GitHub Actions + OIDC で plan / apply、日次の drift 検知）、Slack からの AMI デプロイ・ロールバック
監視
OpenTelemetry → Grafana Cloud（トレース・ログ・メトリクス）、New Relic、Airbrake。Fluent Bit によるログの S3 長期保管
公開物
resizing-gem（Ruby クライアント）、imagemagick-build、setup-imagemagick（GitHub Action）
